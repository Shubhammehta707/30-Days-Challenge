# 🐍 30 Days Python Coding Challenge

Welcome to my **30 Days Python Coding Challenge!** 🚀

This repository is a collection of 32 Python programming problems designed to improve my coding skills, logical thinking, and problem-solving abilities through consistent practice.

Each program focuses on different Python concepts, starting with conditional statements and progressing towards loops, number logic, patterns, lists, and algorithmic challenges.

## 🎯 Objectives

- Strengthen Python programming fundamentals.
- Improve logical thinking and analytical skills.
- Practice conditional statements and looping techniques.
- Solve real-world logic-based programming problems.
- Develop efficient problem-solving approaches.
- Build consistency through daily coding practice.

## 💻 How to Run

**1. Clone this repository**

```bash
git clone https://github.com/Shubhammehta707/30-Days-Challenge.git
```

**2. Navigate to the project folder**

```bash
cd 30-Days-Challenge
```

**3. Run any Python program**

```bash
python "01. Smart Transactional Validator.py"
```

You can run any of the 32 Python files individually.
